# Genesis Core AGC — Web3 NFT Fan Token Ecosystem

**Genesis Core AGC** is a Web3-native project combining fan tokens, NFT utility layers, and idle-style mechanics on the Polygon PoS network. The project evolves from **v1 AGC (Gold)** to **v2 WAGC (Silver)** while maintaining continuity and transparency.

---

## 🔹 Token Versions

**AGC v1 — Gold (Legacy)**
- ERC-20 token, total supply: 1,000 AGC
- Foundation layer for NFT levels and ecosystem trust
- Status: Completed / Legacy
- Assets: `assets/v1/`
